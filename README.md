# Shahjahan Choice Center — Local Run Guide

This is a minimal Vite + React + Tailwind scaffold containing your `App` component.

Prerequisites:
- Node.js 18+ and npm installed.

Install and run:

```bash
cd /path/to/your/project/"Shahjahan Work" || cd "/Volumes/Office Work/shahjahan"
npm install
npm run dev
```

Open the dev URL printed by Vite (usually http://localhost:5173).

Notes:
- Tailwind is configured; if styles look uncompiled, ensure `npm install` completes successfully.
- The project uses `lucide-react` for icons.
